# Animated Movie Features

Minimal supplementary website for a research paper. Six feature categories, each with a high-value and a low-value scene example.

## Add your clips

Place MP4 files in `videos/` with the filenames listed in `index.html`, e.g. `theory-of-mind-high.mp4` and `theory-of-mind-low.mp4`. You can also edit the filenames in the `features` array near the bottom of `index.html`.

## Publish with GitHub Pages

1. Create a public repository named `animated-movie-features`.
2. Upload `index.html` and the `videos` folder (including your MP4 files).
3. In repository **Settings → Pages**, select **Deploy from a branch**, branch **main**, folder **/(root)**, and save.
4. Your website will be at `https://YOUR-USERNAME.github.io/animated-movie-features/` once deployment completes.

Only publish movie clips you have the right to share. For large video files, consider an appropriately licensed external video host.
